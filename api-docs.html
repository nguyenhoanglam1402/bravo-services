A modern, professional API reference for Bravo Services. Click each section to expand/collapse endpoints.

GET /api/v1/organization/list

Get a list of all organizations.

Sample Response: 
{
  "data": [
    {
      "id": "org-uuid",
      "name": "Bravo Academy",
      "zip_code": "70000",
      "address": "123 Bravo St, HCMC",
      "country": "Vietnam",
      "email": "contact@bravo.vn",
      "owner_id": "user-uuid",
      "created_at": "2025-06-10T10:00:00Z",
      "updated_at": "2025-06-10T10:00:00Z"
    }
  ]
}
Response Table:
Field Type Description
data array List of organizations

POST /api/v1/organization/search

Search organizations by name, email, or address (partial match).

Request Body:
Field Type Required
query string Yes
Example Request: 
{
  "query": "Bravo"
}
Example Response: 
{
  "data": [
    {
      "id": "org-uuid",
      "name": "Bravo Academy",
      "zip_code": "70000",
      "address": "123 Bravo St, HCMC",
      "country": "Vietnam",
      "email": "contact@bravo.vn",
      "owner_id": "user-uuid",
      "created_at": "2025-06-10T10:00:00Z",
      "updated_at": "2025-06-10T10:00:00Z"
    }
  ]
}
Response Table:
Field Type Description
data array List of organizations matching the search query

POST /api/v1/version/commit

Commit a new version to a branch.

Request Body:
Field Type Required
branch_id string (UUID) Yes
author_id string (UUID) Yes
raw_data string Yes
message string No
comp_data string No
Example Request: 
{
  "branch_id": "branch-uuid",
  "author_id": "user-uuid",
  "raw_data": "{\"content\":\"Initial\"}",
  "message": "Initial commit",
  "comp_data": ""
}
Example Response: 
{
  "message": "commit version successfully"
}
Response Table:
Field Type Description
message string Status message
